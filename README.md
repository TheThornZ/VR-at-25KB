# VR-at-25KB
Four HTML5 VR experiences for android phone and chrome browser only 25KB

Was messing around with phone VR and HTML5 as well as compression from my previous HTML5 project. This is what I came up with. Works best with Android & chrome browser. Just about any phone and VR phone case will work as long as the browser handles HTML5. Please note files must be hosted somewhere to work. Running an HTML5 file nativley does not allow camera, gyroscope or accelerametor. Both and uncompressed code version and compressed code versions avalible. Feel free to edit the engines and code anyway you want but please give credit to me where possible. 

Roller Coaster VR Demo - No gyro or accelerometer required.
https://geeknfreak.com/VR/RCVR.htm

Car VR - A simple avoid and hit VR car game that only requires an accelerometer  
https://geeknfreak.com/VR/CARVR.htm

Zombie VR - Full 360 degree low poly zombie shooter. Look and Aim and don't get bit.
https://geeknfreak.com/VR/ZOMVR.htm

NearSighted VR Augmented Aid Web Version 1.0 - An HTML5 version of an app I created over 10 years ago. Now it can run in a browser and is only 4KB. Must allow camera and also works well with most Bluetooth controllers.
https://geeknfreak.com/VR/NVRAA.htm
